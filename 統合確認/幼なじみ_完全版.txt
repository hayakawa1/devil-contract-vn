# 幼なじみルート - 完全版（全分岐統合）

このファイルは、幼なじみルートの全分岐を確認するための統合版です。
実際のゲームでは、プレイヤーの選択によってルートが分岐します。

================================================================================
【エンディング到達条件】
================================================================================

■ END1：ハッピー「新しい家族」
- 真実ルートを選択
- 解毒剤を飲まない（または受け取っても破棄）
- 母が最後に"触れる"を選ぶ

■ END2：ビター「戻れない時間」
- 真実ルートでも偽装ルートでも可
- 解毒剤を飲む
- 母の受容が「元の姿限定」になる

■ END3：バッド「家出」
- 偽装ルート（嘘が露見）
- または真実ルートでも母が拒絶固定
- 解毒剤が「使えない／使わない」
- 主人公の家へ転がり込む


================================================================================
【テーマ】
================================================================================

家族との関係 / アイデンティティ

**核心的問い：**
「元に戻る」ことは、本当に「救い」なのか？
母親は「娘」を見ているのか、それとも「安心できる娘像」を見ているのか？


================================================================================
【悪魔との関わり方】
================================================================================

主に「拒絶」寄り
ただし、「無自覚に使う」地雷分岐あり（バッドEND）

悪魔の役割：
- 解毒剤という「選択肢」を提示
- 「戻る＝救い」という固定観念を揺さぶる
- バッドENDでは「居場所の代替」を作ったことを指摘


================================================================================
【分岐ポイント詳細】
================================================================================

## 分岐A：母親との和解方法（中盤）

### 選択肢1「正直に話す」（真実ルート）
- 母親に娘であることを証明
- 声や記憶で母の心を動かす
- 母は恐怖と罪悪感の間で揺れる

### 選択肢2「嘘をつく（双子設定など）」（偽装ルート）
- 双子の姉という嘘で母を安心させる
- 母は「安心できる物語」を選ぶ
- 後で嘘が露見する可能性


## 分岐B：解毒剤の扱い（後半）

### 選択肢1「受け取る」（保留）
- 悪魔から解毒剤を受け取る
- 後で幼なじみに選択を委ねる
- 飲むか飲まないかでENDが分岐

### 選択肢2「受け取らない」（拒絶）
- 悪魔のルールに乗らない
- 解毒剤のない世界で生きる
- 母の受容度でENDが分岐


================================================================================
【フラグ管理イメージ】
================================================================================

```
trust_level（信頼度）：
- 真実ルート選択時 +30
- 偽装ルート選択時 -20
- 第3話で主人公が母を説得 +10

mother_acceptance（母の受容度）：
- 真実ルート選択時 +20
- 偽装ルート選択時 0
- 嘘が露見 -50

antidote_used（解毒剤使用）：
- 受け取る → True（後で使用判定）
- 受け取らない → False

ending_conditions：
- ハッピー：trust_level >= 50 AND mother_acceptance >= 40 AND antidote_used == False
- ビター：antidote_used == True
- バッド：mother_acceptance < 20 OR （偽装ルート AND 嘘が露見）
```

【制作メモ】
================================================================================

## このルートの特徴

1. **「元に戻る＝ハッピー」を否定**
   - 解毒剤で元に戻ってもビターEND
   - 筋肉のままでもハッピーEND可能

2. **母娘関係の複雑さ**
   - 母は娘を愛しているが、「変わった娘」は恐怖の対象
   - 「受容」と「恐怖」の間で揺れる

3. **悪魔の役割**
   - 解毒剤という「安易な解決策」を提示
   - しかし、それは本当の解決にはならない
   - バッドENDでは「依存関係」を作ったことを指摘

4. **Phase 1の土台**
   - フラグ管理の基礎
   - 悪魔分岐の標準形
   - 解毒剤処理のテスト

このルートで確立したシステムが、他のルートでも使い回せる。

   - それ以上増やすと管理が複雑化

2. **エンディングは2〜3種類**
   - ハッピー、ノーマル/ビター、バッド

3. **悪魔台詞は共通ファイルから引用**
   - 共通/悪魔台詞集.txt を参照

4. **フラグ名は統一**
   - trust_level、muscle_acceptance、secret_revealed など

5. **「解毒剤＝救済」にしない**
   - このルートの核心コンセプトを維持
