## 使用方法
1. ChatGPTでDALL-E画像生成を使用
2. 上記プロンプトをそのまま入力
3. 生成された画像を `game/public/assets/characters/` に保存
4. ファイル名規則:
   - `heroine1_normal.png` (幼なじみ・通常)
   - `heroine1_stage1.png` (幼なじみ・第1段階)
   - `heroine1_stage2.png` (幼なじみ・第2段階)
   - `heroine1_stage3.png` (幼なじみ・第3段階)
   - `heroine1_stage4.png` (幼なじみ・第4段階)
   - 同様に `heroine2_〜` (生徒会), `heroine3_〜` (ギャル), ...
   - `protagonist.png` (主人公)
   - `devil.png` (悪魔)

## 注意事項
- 立ち絵は必ず全身を含める
- 背景は白一色（white background）
- 影はキャラクターのみ、背景に影をつけない
- 各段階で表情・制服の破れ具合・筋肉量を明確に変化させる
- 第2段階が「主人公の理想」、第4段階が「人外」という温度感を保つ
