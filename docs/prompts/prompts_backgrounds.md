## 使用方法
1. ChatGPTでDALL-E画像生成を使用
2. 上記プロンプトをそのまま入力
3. 生成された画像を `game/public/assets/backgrounds/` に保存
4. ファイル名: `classroom.png`, `hallway.png` など

## 注意事項
- 必ず16:9の横長フォーマット
- キャラクターは一切含めない（"no characters"を必ず指定）
- アニメ調の背景美術スタイル
- ビジュアルノベルで使用できる汎用性のある構図
