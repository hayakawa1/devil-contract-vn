# 悪魔との契約 - ルート分岐設計書

## 📊 全体構造

```
共通プロローグ（悪魔との契約 → 7人筋肉化）
        ↓
    キャラ選択
        ↓
  各キャラルート開始
        ↓
    重要選択肢（2〜3箇所）
        ↓
   マルチエンディング（各キャラ2〜3種類）
```

**総エンディング数：15〜21種類**

---

## 🎯 共通分岐ポイント（全ルート共通）

### 分岐1：筋肉化への態度
- **受容ルート**：「これも悪くない」→ ポジティブ展開
- **葛藤ルート**：「元に戻りたい」→ シリアス展開

### 分岐2：主人公との関係性
- **恋愛深化**：恋人関係を確立
- **関係模索**：友情と恋愛の境界

### 分岐3：悪魔との関わり方
- **利用する**：悪魔の力を自分の目的に使う（オタク・ギャル向き）
- **拒絶する**：悪魔を完全に排除しようとする（生徒会・幼なじみ向き）
- **無自覚に使う**：気づかないうちに悪魔の思惑通りに（不良・妹ルートの地雷）

**重要**：どの選択も「悪」になりうる構造。正解は存在しない。

## 👥 各キャラルート詳細分岐

### 1. 幼なじみルート「帰れない家」

**テーマ：家族との関係 / アイデンティティ**

#### 分岐ポイントA（中盤）：母親との和解方法
- **選択肢1「正直に話す」** → 真実ルート
- **選択肢2「嘘をつく（双子の妹など）」** → 偽装ルート

#### 分岐ポイントB（後半）：解毒剤の有無
- **受け取る** → 元に戻る選択肢が出現
- **受け取らない** → 筋肉のまま進行

#### エンディング（3種類）
1. **ハッピーEND「新しい家族」**
   - 母親が受け入れる、筋肉のまま家族関係修復
   - 主人公と恋人に

2. **ビターEND「戻れない時間」**
   - 解毒剤で元に戻る、でも主人公との関係は友達のまま
   - 「あの時の自分は本当の自分だったのか」葛藤

3. **バッドEND「家出」**
   - 母親と和解できず、主人公の家に居候
   - 依存関係に

## 🎭 この設計の核心コンセプト

### 「解毒剤＝救済」ではない

この作品最大の特徴：

```
元に戻る ≠ ハッピー
戻らない ≠ 覚悟

むしろ：
元に戻る = 人格破壊の可能性
戻らない = 新しい自己の確立
```

**特に重要なルート：**
- **生徒会**：完璧主義が筋肉で崩壊 → 元に戻ると「弱い自分」に逆戻り
- **オタク**：研究途中で戻ると「知的好奇心の死」
- **幼なじみ**：戻っても「母との溝」は埋まらない可能性

**これにより：**
どのエンディングも「正解」ではなく「選択の結果」になる。
