## 使用方法

これらの特殊イベントは、メインシナリオの合間に挿入可能。
- コメディリリーフとして
- キャラクター関係性の深化として
- 筋肉化の段階的な描写として

各イベントは独立しているため、プレイヤーの選択や進行度に応じて任意に発生させられる。

---

## 演出ポイント

1. **コメディとホラーの境界線**: 笑えるけど、どこか不安になる描写を心がける
2. **日常の崩壊**: 普通の学園イベントが、筋肉によって異常な光景になる対比
3. **周囲の反応**: モブキャラの困惑・驚愕が、状況の異常性を際立たせる
4. **エスカレーション**: イベント内で徐々に事態が悪化していく構造
5. **悪魔の影**: 楽しいイベントの最後に、悪魔が不穏な一言を残す

これらのイベントは、物語全体のダークな雰囲気を中和しつつ、
同時に「異常な日常」を印象づける役割を果たす。
